# 미니 게임 모음

브라우저로 파일을 열면 바로 플레이할 수 있습니다.

## 몬티홀 쇼 (`index.html`)

몬티홀 문제를 직접 체험해보는 게임입니다.

- 문을 고르면 사회자가 염소 문을 열어주고, 유지할지 바꿀지 선택
- 3개 / 10개 문 모드
- 1,000판·10,000판 자동 시뮬레이션으로 유지(약 33%) vs 바꾸기(약 67%) 승률 비교

## 2인 미니 축구 (`soccer.html`)

한 키보드로 두 명이 하는 3대3 축구입니다. 경기 시간은 3분입니다.

| | 이동 | 패스 | 슛 | 감아차기 |
|---|---|---|---|---|
| 1P 레드 | W A S D | E | R | Q |
| 2P 블루 | I J K L | O | P | U |

패스는 동료에게 자동으로 가고, 슛은 골키퍼가 없는 쪽 골대 구석으로 자동 조준됩니다. 감아차기는 골대 바깥쪽으로 날아가다가 휘어서 구석에 꽂힙니다.

## 카이팅 훈련장 (`kiting.html`)

우클릭 이동·좌클릭 공격으로 쫓아오는 적을 때리고 빠지는 카이팅 연습 게임입니다. [바로 열기](kiting.html)

- 공격 선딜레이 중에 움직이면 공격이 취소되고, 쿨다운 중에 공격을 누르면 제자리에 멈춰 기다림
- 금색 링이 다 차면 다음 공격 가능. 쏘고 → 우클릭으로 빠지고 → 링이 차면 다시 좌클릭
- 쉬움 / 보통 / 어려움 난이도, 멈춰 선 시간·헛클릭·분당 공격 수 기록

| 조작 | 키 |
|---|---|
| 이동 | 우클릭 |
| 공격 | 좌클릭 (A + 좌클릭: 커서에 가까운 적) |
| 정지 | S |
| 시작 / 재시작 | Space |
