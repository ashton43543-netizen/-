# Arcane Drift 제출 가이드 (Beatus 2026 GMC)

제출물은 **실행 파일(.exe)**, **시연 영상**, **개발 일지·프로젝트 문서** 세 가지입니다.
아래 순서대로 하면 됩니다.

---

## 1. 최신 게임 파일 넣기

1. GitHub 리포지토리(https://github.com/ashton43543-netizen/-)에서
   `arcane-drift/Assets/Scripts/ArcaneDriftGame.cs` 를 엽니다.
   오른쪽 위 **다운로드 아이콘(Download raw file)** 을 눌러 받습니다.
2. Unity 프로젝트의 **Assets** 폴더에 있던 예전 `ArcaneDriftGame.cs` 를 **먼저 지웁니다.**
   `ArcaneDriftGame (1).cs` 처럼 번호가 붙은 복사본도 모두 지웁니다.
   남아 있으면 "클래스 중복" 에러가 납니다.
3. 받은 파일을 Assets 에 넣습니다. 이름이 정확히 `ArcaneDriftGame.cs` 인지 확인합니다.
4. ▶ 를 눌러 게임이 잘 되는지 확인합니다. 아래 **Console** 창에 빨간 에러가 없어야 합니다.

---

## 2. 빌드 전 설정 (한 번만)

**Edit → Project Settings → Player** 를 엽니다.

| 항목 | 넣을 값 |
|---|---|
| Company Name | 팀 이름 |
| Product Name | `Arcane Drift` (exe 파일 이름이 됩니다) |
| Resolution and Presentation → Fullscreen Mode | **Windowed** 를 권장합니다 |
| Default Screen Width / Height | 1280 / 720 |
| Other Settings → Active Input Handling | **Both** (에러가 나지 않으면 그대로 둬도 됩니다) |

> ⚠️ 게임 안에 "게임 종료" 버튼이 없습니다.
> 전체 화면으로 만들면 **Alt + F4** 로만 끌 수 있습니다.
> 그래서 창 모드(Windowed)를 권장합니다. 종료 버튼이 필요하면 말해 주세요. 추가해 드리겠습니다.

---

## 3. .exe 만들기

1. **File → Build Profiles** 를 엽니다. Unity 2022.3 에서는 **File → Build Settings** 입니다.
2. 플랫폼 목록에서 **Windows** 를 고릅니다.
   - Windows 가 목록에 없으면 Unity Hub → **Installs** → 쓰는 버전의 톱니바퀴 → **Add modules** →
     **Windows Build Support** 를 설치합니다.
3. **Add Open Scenes** 를 눌러 지금 열린 씬을 목록에 넣습니다.
   - 씬이 저장되지 않았다면 먼저 **Ctrl + S** 로 저장합니다.
4. **Build** 를 누릅니다.
   **빈 폴더**를 새로 만들어 고릅니다. 예: `바탕화면\ArcaneDrift_Build`
5. 다 되면 그 폴더에 아래 파일들이 생깁니다.

```
ArcaneDrift_Build/
├─ Arcane Drift.exe
├─ Arcane Drift_Data/      ← 꼭 같이 있어야 실행됨
├─ MonoBleedingEdge/
└─ UnityPlayer.dll
```

---

## 4. 제출 전 확인

`Arcane Drift.exe` 를 더블클릭해서 아래를 확인합니다.

- [ ] 타이틀 화면이 나오고 **시작하기** 가 눌린다
- [ ] 우클릭 이동, 좌클릭 공격, **Q W E R** 스킬이 된다
- [ ] 레벨업 카드를 고를 수 있다 (1~4 키 또는 클릭)
- [ ] **Esc** 로 일시정지가 되고 **다시 시작** 이 된다
- [ ] 죽으면 게임 오버 화면에서 **다시 시작** 이 된다
- [ ] 한글이 네모(□)로 깨지지 않는다

> 다른 컴퓨터에서도 한 번 실행해 보면 가장 확실합니다.
> 예를 들어 학교 컴퓨터나 USB에 담아서 실행해 봅니다.
> 한글은 윈도우에 기본으로 있는 글꼴을 쓰기 때문에 보통 문제가 없습니다.

---

## 5. 압축해서 제출

1. 빌드 폴더(`ArcaneDrift_Build`) **전체**를 오른쪽 클릭합니다.
   **압축(ZIP) 파일로 보내기** 를 고릅니다.
   - ❌ `.exe` 하나만 내면 실행되지 않습니다.
     `_Data` 폴더와 `UnityPlayer.dll` 이 같이 있어야 합니다.
2. 파일 이름 예시: `팀이름_ArcaneDrift.zip`

---

## 6. 시연 영상

- **Win + G** 를 누르면 Xbox Game Bar 가 열립니다.
  게임 창에서 **Win + Alt + R** 을 누르면 녹화가 시작되고, 한 번 더 누르면 멈춥니다.
- 녹화된 영상은 `동영상\캡처` 폴더에 저장됩니다.
- 영상에 넣으면 좋은 장면:
  1. 타이틀 화면
  2. 이동과 공격
  3. 레벨업 카드 고르기
  4. Q W E R 스킬 사용
  5. 평타 강화 효과 (감전, 화염 등)
  6. 보스
  7. 게임 오버와 다시 시작

## 7. 개발 일지·프로젝트 문서에 쓸 것

- **게임 소개**
  - 장르: 탑다운 액션, 무한 모드
  - 목표: 쓰러질 때까지 버티기 (생존 시간과 처치 수 기록)
- **조작**
  - 우클릭: 이동
  - 좌클릭: 공격할 적 지정
  - Q W E R: 스킬 (11종 중 4개)
  - Tab: 내 빌드 보기
  - Esc: 일시정지
- **핵심 시스템**
  - 레벨업 증강 카드
  - 스킬 11종 (배우면 Q W E R 칸에 들어감)
  - 평타 강화 패시브 6종 (감전, 화염, 서리, 맹독, 분열, 처형)
  - 엘리트 22초마다, 보스 90초마다, 대형 보스 360초마다 등장
- **에셋 출처**
  - 그림은 모두 코드로 직접 그린 도트입니다.
  - 외부 에셋은 쓰지 않았습니다.
  - 대회는 무료 에셋 사용을 권장하므로, 감점 요인이 되는지 선생님께 확인하세요.
- **AI 사용**
  - 코드 작성에 Claude 를 사용했습니다.
  - 대회 규정에 AI 관련 내용이 없었으므로, 문서에 밝히고 선생님께 확인받는 것을 권장합니다.
- **미션 인증 단계별 기록**
  1. 뼈대
  2. 핵심 로직
  3. 그래픽
  4. 마감
  - 각 단계에서 무엇을 했는지 날짜와 함께 적습니다.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| Build 버튼을 눌렀는데 에러 | Console 의 빨간 에러를 확인합니다. 대부분 Assets 에 예전 스크립트가 남아 있는 경우입니다 |
| 빌드할 씬이 없다는 메시지 | 3번의 **Add Open Scenes** 를 눌러 씬을 목록에 넣습니다 |
| exe 가 안 켜진다 | `_Data` 폴더가 exe 옆에 있는지 확인합니다 |
| 창을 끌 수가 없다 | Alt + F4 로 끕니다. 2번에서 Windowed 로 바꾸고 다시 빌드합니다 |
